# Nava

Elegant local music player with unlimited playlists, equalizer, background playback and Islamic geometric design.

## Features
- Local music library scan
- Unlimited playlists
- Background playback + MediaStyle notification
- Equalizer
- English UI with Persian font support
- Islamic (Eslimi) geometric background
- Modern Material 3 design

## Build
Open in Android Studio and run **Build → Build APK(s)**.
Or download from GitHub Actions artifacts.
